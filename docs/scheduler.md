# Scheduler Guide

> Automate repetitive tasks and never forget a report again. Set it once, and IMS handles it forever.

## Overview

The IMS Scheduler lets you create automated tasks that run at specific times. Instead of manually generating reports, checking inventory, or sending alerts — schedule them to happen automatically.

**No cron jobs. No server management. Just tell the AI when and what.**

---

## Why Automate?

### The Manual Reality

Every business has repetitive tasks:

| Daily Tasks | Weekly Tasks | Monthly Tasks |
|-------------|--------------|---------------|
| Check low stock | Sales summary | Revenue report |
| Review pending orders | Supplier orders | Inventory audit |
| Send daily report | Stock reconciliation | Tax calculations |
| Update dashboards | Performance review | Backup data |

**Manual approach:** Remember to do each task → Do it → Hope you didn't forget anything

**Automated approach:** Set up once → Tasks run automatically → Get results delivered

## How It Works

### Step 1: Create a Task
Tell the AI what you want and when:
```
"Every Monday at 8 AM, send me a low stock report via email"
```

### Step 2: AI Schedules It
The AI:
1. Understands your request
2. Selects appropriate tools (analytics + gmail)
3. Creates the scheduled task
4. Confirms the schedule

### Step 3: Task Runs Automatically
- At the scheduled time, IMS executes the task
- Results are delivered (email, dashboard, etc.)
- You review when convenient

### Step 4: Track History
View all past executions:
- What ran
- When it ran
- Results/status
- Any errors

## Available Tools for Scheduling

When creating a scheduled task, you can use up to 3 tools:

| Tool | What It Does | Example Use |
|------|--------------|-------------|
| **analytics** | Generate reports, calculate metrics | "sales summary", "inventory health" |
| **gmail** | Send emails | "email report to manager" |
| **export** | Create CSV/Excel files | "export inventory list" |
| **web_search** | Search internet | "check competitor prices" |
| **file_search** | Search uploaded files | "find last month's invoice" |
| **inventory** | Access item data | "list low stock items" |
| **billing** | Access bill data | "today's sales" |

### Tool Combinations

**Report + Email:**
```
Tools: analytics + gmail
"Weekly sales report emailed to team"
```

**Check + Alert:**
```
Tools: inventory + gmail
"Alert when any item below 5 units"
```

**Export + Email:**
```
Tools: export + gmail
"Monthly inventory CSV to accountant"
```

## Best Practices

### 1. Start Simple
Begin with one or two tasks, then expand:
```
Week 1: Daily inventory summary
Week 2: Add weekly sales report
Week 3: Add monthly analytics
```

### 2. Stagger Timing
Don't schedule everything at the same time:
```
❌ All reports at 9 AM
✅ Morning report: 8:30 AM
   Mid-day check: 1:00 PM
   Evening summary: 5:30 PM
```

### 3. Use Meaningful Names
```
❌ "Task 1"
✅ "Daily Low Stock Alert - Electronics"
```

### 4. Review History Weekly
Check task execution history to:
- Identify failures
- Adjust timing
- Remove unused tasks

### 5. Connect Gmail First
Email delivery requires Gmail connection:
1. Go to Settings → Connectors
2. Connect Gmail with OAuth
3. Then schedule email tasks

## Troubleshooting

### Task Not Running

**Check:**
1. Is the task still active (not paused)?
2. Is the scheduled time in the future?
3. Are required tools connected (e.g., Gmail)?

### Email Not Sending

**Check:**
1. Gmail connector status in Settings
2. Recipient email address validity
3. Task execution history for errors

### Wrong Data in Reports

**Check:**
1. Date range in task query
2. Filter conditions
3. Run task manually to verify

## API Reference

### Create Task
```http
POST /scheduler/tasks
Authorization: Bearer YOUR_TOKEN
```
```json
{
  "query": "Send low stock report",
  "scheduled_at": "2025-01-20T09:00:00Z",
  "tools": ["analytics", "gmail"],
  "recurrence": "daily"
}
```

### List Tasks
```http
GET /scheduler/tasks
```

### Get Task Details
```http
GET /scheduler/tasks/{id}
```

### Cancel Task
```http
DELETE /scheduler/tasks/{id}
```
